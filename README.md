Многопользовательский мессенджер, разработанный на языке C++ с использованием TCP-сокетов, библиотеки Qt и сквозного шифрования сообщений.

## Возможности

* обмен сообщениями в реальном времени;
* клиент-серверная архитектура;
* сквозное шифрование (End-to-End Encryption);
* обмен ключами с использованием библиотеки libsodium;
* графический интерфейс на Qt;
* многопоточная обработка сообщений;
* модульные тесты на базе Doctest;
* автоматическая генерация документации через Doxygen.

## Архитектура проекта

Проект состоит из следующих основных модулей:

* **TcpServer** — принимает подключения клиентов и пересылает сообщения;
* **TcpClient** — подключается к серверу и обеспечивает обмен сообщениями;
* **Crypto** — выполняет обмен ключами, шифрование и расшифровку сообщений;
* **ChatClient** — связывает сетевую часть приложения с интерфейсом Qt;
* **MainWindow** — главное окно приложения;
* **ConnectDialog** — диалог подключения к серверу.

## Требования

### Для сборки и запуска

* C++17-совместимый компилятор;
* CMake 3.16 или новее;
* Qt6;
* libsodium.

### Для генерации документации

* Doxygen 1.17 или новее.

## Сборка проекта

### Консольная версия

cmake -B build
cmake --build build

### Графическая версия

cd gui
cmake -B build
cmake --build build

## Запуск сервера

./server

После запуска сервер начинает прослушивание указанного порта и ожидает подключения клиентов.

## Запуск клиента

./messenger_gui

После запуска необходимо указать:

* имя пользователя;
* IP-адрес сервера;
* номер порта.

## Тестирование

Из каталога сборки:

ctest

## Документация
